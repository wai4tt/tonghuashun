# 咨询页的3秒研究

咨询页默认选择「3秒研究」，请求使用 `research_mode: instant`。它使用已加载且仍在有效期内的事实，完成指标展示、简短的指标关系分析、规则维度检查、同项资料冲突检查、证据血缘核验及固定风险检查。分析仅使用引用到的指标，例如核对同一期营收与利润增速是否背离，以及结合市盈率和净资产收益率说明估值判断的边界；不会凭单一指标推断买卖结论。没有资料时返回明确缺项；概念问题返回概念解释；这些答复不计入已完成证据研判数量。

## 为响应速度削减的范围

提交问题后不再同步调用在线模型、补取资料、读取公告全文、全市场筛选、计算收益预测或生成交易指令。复杂多轮意图不作猜测。完整在线模型报告仍可在股票页后台预生成，并在证据及审核通过后交付。`research_mode: deep` 表示完整在线研究，不设整次研究的总时限；单次模型和数据源调用仍保留故障超时，不属于3秒咨询协议。

已有资料的研判结果属于 `response_scope: evidence_review`，不会标成完整在线报告或自动升级为审核通过。估值、盈利等问题优先展示相应指标；不同证券分别展示，缺失维度不会补造中性分数。原始数值字符串和证据记录保持不变，只在展示计算时读取有限的数值。百分比只有明确口径才可展示；价格单位未知时会说明。行情时效仍为60秒，过期价格不会展示为最新价格。

## 响应路径

资料通过原有页面预取和资料面板提前加载。概览接口同时预计算本地规则指标。短咨询使用独立执行和准入队列，避免等待完整研究。后端处理预算不超过2.6秒，前端短请求不进行退避重试；历史记录异步保存，响应中保留待保存状态。折叠的图表和数据溯源表只在展开时渲染，以减少首次回答的表格依赖开销。

3秒是已初始化页面提交后获得有限范围答复的目标，预取时间、冷启动和完整在线报告生成时间分别计量。网络、设备卡顿或超负载仍可能导致超时；此时返回明确错误，不把超时计为研究完成。

## 验收

```powershell
.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.venv\Scripts\python.exe scripts/verify_instant_research.py --samples 3
.venv\Scripts\python.exe scripts/verify_instant_research.py --live --samples 3 --output outputs/testing/20261104-instant/live-final.json
```

`--live` 使用已配置问财API，并行获取行情和财务、创建明确命名的QA账号、确认测试画像，测试实际鉴权、咨询最终响应及历史保存。报告不保存密码或令牌。需要同时检查每条样本的 `checked`、`within_3_seconds` 和 `response_scope`；不能只检查HTTP 200。真实行情记录、合成测试记录及浏览器观测分开保存。

本次证据位于 `outputs/testing/20261104-instant/`。早期 `live.json` 保留上游连接失败记录，恢复后的实际结果以 `live-final.json` 和最终汇总为准。
