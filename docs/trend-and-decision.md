# 走势观察、指数看板与投资价值比较

本文说明本轮新增的六个能力（行业分析、五日均线、指数、连续三日上升高度、走势图、
中和判断走势）与三项研究能力（自选名称补全、投资建议对比决策、结构化投资分析报告）
的实现口径、接口与边界。所有数值都由固定规则计算，可复算、可追溯，不调用模型。

## 一、边界：技术观察不进入投资证据链

- 走势类数据（收盘价/单位净值/指数点位）只用于图表与描述性判断，**不写入
  投资建议的 `facts`、`evidence`、合规审核与 `research_report` 的证据维度**。
  这是项目原有的分层：`/api/v1/data/price-history` 仅服务于走势图。
- 走势判断回答的是“过去 N 个交易日的价格结构是什么样”，不是“未来会涨还是会跌”。
  界面固定展示这句话，导出文本同样保留。
- 缺失数据不插值、不补零：同一交易日出现两个互相矛盾的收盘价时，整条剔除并
  在说明中记录冲突条数。

## 二、数据来源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 个股/可转债收盘价 | `hithink-market-query` | 近 30 / 60 个交易日，逐日列日期 |
| 基金单位净值 | `hithink-fund-query` | 同上 |
| 指数收盘点位 | `hithink-market-query` | 上证、深证、创业板、沪深300、中证500、科创50 |
| 行业指数点位 | `hithink-industry-query` | 按“查询行业”选择的行业名称查询 |
| 指数最新价、涨跌幅、成交额 | `hithink-market-query` | 固定模板，用户不能指定能力或参数 |

供应商返回的列名可能是 `收盘价[20260601]`、`收盘点位[20260601]`、`指数@收盘价[...]`，
适配器统一去掉 `指数@/板块@/行业@` 前缀后按列名口径匹配；行内日期优先，其次取
`交易日期/日期` 字段。没有真实日期的数值一律丢弃。

## 三、五日均线（MA5）

- MA5 窗口为 5 个交易日，采用简单移动平均；不足 5 个交易日的位置返回空值，
  不向前填充。
- 返回值包含：最新 MA5、MA5 与前一日的斜率（%）、收盘价相对 MA5 的偏离（%）、
  完整 MA5 序列（与收盘序列按日期对齐，用于图上虚线）。
- 少于 6 个交易日（5 日均线 + 前一日的 MA5 用于算斜率）时，明确返回
  `available=false` 并说明原因，不给出方向。

## 四、连续三日上升高度

- 取最近 4 个交易日收盘价 `C[t-3..t]`：
  - 三日累计涨幅 `change_pct = (C_t / C_{t-3} - 1) × 100`
  - 上升高度 `height = C_t - C_{t-3}`（与行情同一计价单位；指数为点）
  - 逐日涨跌幅 `daily_changes_pct`（3 个）
  - `all_up`：三天逐日上涨才为真
  - `consecutive_up_days`：截至最新交易日的连续上涨天数
- 不足 4 个交易日返回 `available=false`。
- 界面同时展示“累计涨幅 + 高度 + 连续上涨天数”，避免只看百分比忽略绝对高度。

## 五、中和判断走势

“中和”指多空信号同时成立时不做单边结论。六个信号分别归一化到 `[-1, 1]`，
按权重加权；缺失信号整体退出并重新归一化权重，不按 0 分参与。

| 信号 | 计算 | 满分幅度 | 权重 |
| --- | --- | --- | --- |
| 五日均线斜率 | `MA5_t / MA5_{t-1} - 1` | ±2.5% | 0.28 |
| 收盘价相对 MA5 | `C_t / MA5 - 1` | ±3% | 0.16 |
| MA5 相对 MA20（不足 20 日用 MA10） | `MA5 / MA20 - 1` | ±3% | 0.20 |
| 三日累计升幅 | `C_t / C_{t-3} - 1` | ±6% | 0.20 |
| 近五日方向一致性 | `(上涨天数 - 2.5) / 2.5` | ±1 | 0.16 |
| 相对基准强弱（可选） | 最近 5 个共同交易日超额涨幅 | ±4% | 0.15 |

- 综合分 `score = 50 + 50 × Σ(w·s)/Σw`，范围 0–100。
- 档位：≥65 上行；55–65 偏强震荡；45–55 震荡；35–45 偏弱震荡；<35 下行。
- **中和规则**：若同时存在 `s ≥ 0.4` 与 `s ≤ -0.4` 的信号，无论综合分多少，
  一律降级为“震荡”，并输出“按中和原则不给出单边结论”。
- 置信度 `= 0.45 × 数据充分度 + 0.55 × 信号一致度`：
  - 数据充分度 `= min(1, (交易日数 - 5) / 15)`
  - 信号一致度 `= 1 - 平均(|s_i - 综合分|) / 2`
- 输出包含每个信号的读数、方向、得分、权重与解释，界面可展开逐项核对。

## 六、指数看板

- 一次读取 6 个主要指数：上证指数、深证成指、创业板指、沪深300、中证500、科创50。
- 每个指数返回：最新点位、涨跌幅、成交额、交易日、MA5、三日累计升幅与高度、
  中和判断档位与综合分、30 日点位序列、完整分析对象。
- 创业板指、科创50 等以沪深300 为基准计算 5 日相对强弱；沪深300 自身不与自己比较。
- 单指数历史点位缺失只影响该卡片（`status=empty`），其余指数照常返回
  （整体 `status=partial`），不把一次失败渲染成“全部无数据”。
- 服务端 60 秒有界缓存 + 同一请求合并，避免轮询打爆数据源。

## 七、行业分析

- 行业页保留涨跌幅/资金/估值排名与行业对比图；新增“行业走势与中和判断”：
  用户选择具体行业后，按需读取行业指数点位，展示 MA5、三日升幅、走势图与信号拆解。
- 行业走势同样不进入咨询证据；咨询时仍需在问题中写明行业，系统按既有意图路由取数。

## 八、自选研究：把股票名称读过来

三层名称来源，逐层回退，任一环节失败都不影响自选本身：

1. 添加自选时向后端发起一次只读查询（`hithink-market-query` 等），要求返回记录
   的证券代码与输入一致才接受名称；名称写入 `watchlist_items.name` 列。
2. 行情返回的 `entity` 名称（数据源核实）。
3. 用户原始输入。

旧库启动时自动补列（`ALTER TABLE watchlist_items ADD COLUMN name VARCHAR(60)`），
不需要手工迁移。对比表头、详情下拉、走势选择器统一显示“名称 · 代码”。

## 九、投资建议对比与决策

横向比较 2–4 个**同类型**标的后，后端按确定性规则给出排序与结论：

| 维度 | 默认字段（同组必须同字段） | 方向 | 权重 | 绝对区间（示例） |
| --- | --- | --- | --- | --- |
| 估值 | `pe_ttm`，无效时整组改用 `pb` | 越低越好 | 0.25 | PE ≤10→90，10–20→70，20–35→50，35–60→30，>60→15 |
| 成长 | `revenue_growth` / `net_profit_growth` | 越高越好 | 0.25 | ≥30%→90，15–30%→75，5–15%→60，0–5%→45，<0→25 |
| 盈利质量 | `roe` / `roe_weighted` | 越高越好 | 0.20 | ≥20%→90，12–20%→75，8–12%→60，4–8%→45，0–4%→30，<0→10 |
| 资金 | `capital_flow` | 越高越好 | 0.15 | 正且较大→75，0–正→50，负→25 |
| 当日表现 | `change` | 越高越好 | 0.15 | 分档 25–90 |

- 维度得分 `= 0.5 × 组内相对档位 + 0.5 × 绝对区间分`，总分按权重归一化到 0–100。
- 亏损公司的负 PE/PB 没有估值含义：不会当成“最便宜”，而是让整组改用市净率；
  两个口径都不可用时该维度整体退出，并列入“未纳入比较的维度”。
- 估值/成长/盈利质量中至少覆盖 2 项、且每个标的都有同口径数值，才输出排序；
  否则返回 `status=insufficient` 并说明缺什么，不给排名。
- 结论文本明确写出“哪个相对更具投资价值、优势与不足、与第 2 名的分差”，
  同时固定声明“不构成买入建议、不是预期收益或上涨概率”。

## 十、结构化投资分析报告

在原有证据对照（研究证据对照）基础上扩展为结构化报告（`ResearchReport v2`）：

- 标题、生成时间、研究对象、审核状态；
- 结论（来自已通过合规闸门的 `conclusion`，不改写）；
- 关键信息（每个维度提炼一条有方向性的证据，标注有利/不利/中性）；
- 数据覆盖（引用条数、可用条数、带日期条数、已覆盖/未覆盖维度、来源分布）；
- 分维度证据与判断限制、重新评估条件；
- 可下载 Markdown（`POST /api/v1/research/report/markdown` 与前端下载按钮共用
  同一渲染实现），JSON 直接随分析响应返回。

“从海量数据提取关键信息”的落地方式是：固定维度 → 每维度按期间取最新同口径值 →
逐条生成“观察 + 解读 + 来源 + 受限条件”，不做加权平均、不把缺失当 0。

## 十一、接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/data/price-history` | 支持股票/基金/可转债/指数/行业；返回点位、`ma5` 序列与 `analysis` |
| POST | `/api/v1/market/index-board` | 六大指数看板（报价 + 走势 + 判断），需登录 |
| POST | `/api/v1/data/compare` | 2–4 个同类型标的；新增 `display_name` 与 `decision` |
| POST | `/api/v1/data/watchlist-quotes` | 自选行情；新增 `display_name` |
| POST | `/api/v1/watchlist` | 添加自选时尽力补全证券名称 |
| POST | `/api/v1/research/report/markdown` | 结构化报告导出 Markdown |
